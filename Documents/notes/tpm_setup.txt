1. Install ukify, sbctl, tpm2-tss
1.5: create secure boot keys, sign, and enable secure boot
2. Add rd.luks.name=...=root to kernel parameters (/etc/cmdline.d/luks.conf)
3. make sure initramfs hooks include systemd, sd-encrypt
4. create /etc/kernel/uki.conf:

# [UKI]
#Initrd=
#Microcode=
#Splash=
#PCRPKey=
#PCRBanks=
# SecureBootSigningTool=systemd-sbsign
# SecureBootPrivateKey=/etc/kernel/secure-boot-private-key.pem
# SecureBootCertificate=/etc/kernel/secure-boot-certificate.pem
#SecureBootCertificateDir=
#SecureBootCertificateName=
#SecureBootCertificateValidity=
#SigningEngine=
#SignKernel=

[PCRSignature:all]
PCRPrivateKey=/etc/systemd/tpm2-pcr-private-key.pem
PCRPublicKey=/etc/systemd/tpm2-pcr-public-key.pem

[PCRSignature:initrd]
Phases=enter-initrd
PCRPrivateKey=/etc/systemd/tpm2-pcr-private-key-initrd.pem
PCRPublicKey=/etc/systemd/tpm2-pcr-public-key-initrd.pem

4. create the keys with ukify genkey (--pcr-private/public-key)
5. regenerate initramfs
6. sudo systemd-cryptenroll --wipe-slot=tpm2 --tpm2-device auto \
                       --tpm2-public-key /etc/systemd/tpm2-pcr-public-key-initrd.pem \
                       --tpm2-with-pin=yes \
                       --tpm2-public-key-pcrs=11 \
                       --tpm2-pcrs=7 \
                       /dev/disk/by-partlabel/<root-partlabel>
